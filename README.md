# Student Performance Tracking System

## Project Overview
The Student Performance Tracking System is a Python-based console application that helps manage student information, attendance, examination marks, and academic performance reports.

## Features
- **Student Management:** Add, view, search, update, and delete student records.
- **Attendance Management:** Record attendance and calculate attendance percentages.
- **Examination Management:** Manage subjects, enter examination marks, and view student results.
- **Performance Reports:** Generate student performance reports, identify top performers, and view class summaries.
- **Database Storage:** Store records using SQLite.

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run the command:

```bash
python main.py
```

5. Follow the menu options displayed in the terminal.

## Database
SQLite stores student details, subjects, attendance records, and examination marks. The database tables are created automatically when the application starts.
